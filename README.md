# Final Project: Personal Mini-Toolkit

## About This Project

My Personal Mini-Toolkit is a simple Python program that brings together the programming skills I learned during this course. It contains three tools: a Number Guessing Game, a To-Do List, and a Simple Calculator.

## Files

- `toolkit_plan.txt`: Contains my project plan, tool descriptions, menu, and programming concepts.
- `toolkit.py`: Contains the complete Personal Mini-Toolkit program with three working tools.

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in your terminal.
3. Run the following command:

`py toolkit.py`

## My Reflection

The hardest part of this project was building the menu loop and making sure each tool returned to the main menu. I used a while loop to keep the program running until the user chooses Quit. The bug that took the longest to fix was handling invalid numbers when removing tasks from the to-do list. I fixed it by checking whether the task number exists before removing an item. I also tested the calculator to make sure it handles division by zero. I am proud that I was able to combine loops, lists, conditions, and functions in one project. With one more week, I would add a feature to save my to-do list so that tasks are still available after closing the program.
